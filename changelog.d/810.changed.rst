The warning emitted when a test is marked with ``asyncio`` but is not handled by pytest-asyncio now distinguishes a test whose coroutine function was marked after collection (e.g. via ``pytest_collection_modifyitems``): it points to the supported ``pytest_pycollect_makeitem`` hook instead of suggesting that the marker be removed. A new how-to guide documents how to apply the ``asyncio`` marker from a plugin.
